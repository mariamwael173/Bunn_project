# Bunn: Demo Coffee Roaster Website

A responsive, dependency-free website built with HTML5, CSS3, and vanilla JavaScript.

## Features
- Mobile-first responsive layout (phone, tablet, desktop)
- Accessible navigation (skip link, keyboard support, ARIA states)
- Interactive menu filter, scroll-reveal animations, validated contact form
- Respects `prefers-reduced-motion`
- No images or frameworks, so it loads fast

## Structure
```
demo-site/
  index.html
  css/style.css
  js/script.js
```

## Run locally
Open `index.html` in a browser. No build step.

## Deploy
Push the folder to GitHub, then enable GitHub Pages (Settings > Pages), or drag the folder into Netlify.

## Notes
Business details and prices are placeholder content. The contact form is a front-end demo and does not send messages.
